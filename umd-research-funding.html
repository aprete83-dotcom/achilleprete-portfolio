How this project works

Python collected public award records from the NSF API. Records were filtered to the exact recipient name, University of Maryland, College Park. Dates, funding amounts, and duplicate award IDs were checked before the data was saved in a Databricks Delta table.

SQL grouped the awards by start year. This interactive page displays those aggregated results.

Funding represents cumulative obligated amounts in the downloaded records, grouped by award start year. It does not represent spending during each calendar year. The dataset covers the collected NSF search results, rather than all UMD research funding.

Data snapshot: October 8, 2026. Updates are currently manual.
